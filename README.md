
# AI Text Summarizer

## Project Description
AI Text Summarizer is a web-based application developed using Python and Streamlit. It uses the Hugging Face Qwen 2.5 AI model to convert lengthy paragraphs into short and meaningful summaries in simple English.

## Objectives
- To summarize lengthy paragraphs automatically.
- To extract important information from text.
- To reduce reading time.
- To provide a simple and user-friendly interface.
- To understand the practical use of AI and Large Language Models.

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- Qwen 2.5 (0.5B Instruct)
- PyTorch

## Features
- Generates short summaries from lengthy text.
- Uses an AI-powered language model.
- Produces summaries in simple English.
- Displays original and summary word counts.
- Provides a simple and attractive user interface.
- Includes a customized sky-blue background

## Installation

Install the required libraries using:

```bash
pip install streamlit transformers torch
```

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python -m streamlit run app.py
```

4. Open the application in your browser.
5. Enter a paragraph in the text area.
6. Click the Generate Summary button.

## Working Process

1. The user enters a lengthy paragraph.
2. The application loads the Qwen 2.5 AI model.
3. The input text is processed by the AI model.
4. The model generates a short summary.
5. The summary and word counts are displayed on the screen.
